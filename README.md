Para correr el programa debermos hacer un clean de la 
compilacion con el comando

->mingw32-make clean

despues debemos hacer la compialcion con el comando
->mingw32-make

 por ultimo ejecutar el cemestre.exe con los parametros validos, siendo
 
./cemestre.exe data/clean/computadores.tsv data/historiales/historial.txt pruebacomputadores.json 

siendo una ruta a un tsv correcto, una ruta a un historial de estudiante y la ruta final del json+
